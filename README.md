# Paper Learning

A research workspace organized around the [Cookiecutter Data Science](https://cookiecutter-data-science.drivendata.org/) (CCDS) folder conventions, with additional folders for reading papers and documenting machine-learning experiments.

> **Status:** This repository contains a project scaffold only. No datasets, experiments, pretrained models, or benchmark results have been added.

## Folder guide

| Path | Purpose |
| --- | --- |
| `data/raw/` | Original datasets (do not edit in place) |
| `data/external/` | Data obtained from third parties |
| `data/interim/` | Temporary or partially processed data |
| `data/processed/` | Final modeling-ready datasets |
| `notebooks/` | Exploratory analysis and research notebooks |
| `src/paper_learning/` | Reusable Python code |
| `models/` | Locally saved models and predictions |
| `reports/figures/` | Figures used in presentations and reports |
| `references/` | Data dictionaries, protocols, and references |
| `docs/` | Project documentation |
| `papers/` | Literature index and paper-reading resources |
| `notes/` | Structured paper-reading notes |
| `experiments/` | Experiment plans, configurations, and result summaries |
| `tests/` | Automated checks |

## Quick start

Requires Python 3.10+.

```bash
git clone https://github.com/Tommy0813/paper-learning-.git
cd paper-learning-
python -m venv .venv
```

Activate the virtual environment:

- Windows PowerShell: `.venv\Scripts\Activate.ps1`
- macOS/Linux: `source .venv/bin/activate`

Then install the starter dependencies and run checks:

```bash
python -m pip install -e . -r requirements.txt
python -m pytest
python -m ruff check .
```

The project does not run a full ML pipeline yet: `src/` contains labeled placeholders for future implementations.

## Research workflow

1. Add a paper URL and reading notes to `papers/` and `notes/`.
2. Record dataset source, version, and any license or sharing restriction before using it.
3. Put original data in `data/raw/`. Save transformations to `data/interim/` and `data/processed/`.
4. Explore in `notebooks/`, then move reusable code into `src/paper_learning/`.
5. Document splits, seeds, metrics, baselines, and environment in `experiments/`.
6. Save presentation-ready figures to `reports/figures/`, and describe findings in `reports/`.

**Privacy and storage:** `.gitignore` excludes dataset payloads, trained model files, credentials, local environments, and notebook checkpoints by default. The repository is public; review each file before committing. Small `.gitkeep` files only preserve empty directories.
